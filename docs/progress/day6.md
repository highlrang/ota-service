# Day6
## 구현
### 작업내용
예약 내역 관리 기능을 구현한다.
- Customer / Extranet에서 각각 고객의 예약 내역을 관리할 수 있도록 한다.
  - 예약 목록 및 상세 조회 기능을 구현한다.
  - 예약 취소 기능을 구현한다. 
- Supplier(ONDA) 숙소 예약에 대해 ONDA 예약 동기화 기능을 구현한다.
  - `Accommodation` 이 `Supplier` 타입이거나 supplier_product_id 가 있는 경우 ONDA 예약 API를 호출한다.
  - 예약 생성 전 체크 API로 외부 재고를 확인하고, 예약 취소 시 취소 API를 함께 호출한다.

### 의사결정
- 예약 취소는 `CONFIRMED` 상태에서만 가능하도록 제한한다.
  - 이와 관련해 체크아웃 시각이 지난 예약건에 대해 `COMPLETED`로 상태를 변경하는 1시간 주기의 스케줄링을 추가한다.
  
- 고객 예약 취소는 예약 상태와 결제 상태를 함께 변경하고 환불 이력을 별도 생성한다.
  - 취소 시 예약은 `CANCELLED`, 결제는 `REFUNDED`로 변경하고 `REFUNDS` 테이블에 환불 레코드를 남긴다.
  - 예약 시 차감한 날짜별 재고를 복구한다.

- ONDA 연동 예약은 고객 결제보다 외부 예약 선점을 우선한다.
  - 고객이 결제 외의 요인으로 환불되는 경험을 줄이기 위해 ONDA 예약 생성울 결제보다 먼저 처리한다.
  - ONDA 예약 성공 후 결제가 실패하면 ONDA 취소 API를 호출해 자동 원복한다.
  - ONDA 예약 번호를 내부 예약에 저장해 이후 고객 취소 시 동일 예약을 ONDA에도 취소할 수 있도록 한다.
