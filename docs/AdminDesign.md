# Admin Design

# Admin 기능 설계  
범위는 판매자 관리, 예약 관리, 문의 관리 등 운영 필수 기능을 우선한다.

## 1. 목표
- 판매자와 숙소의 등록 상태를 검수하고 영업 가능 상태를 관리한다.
- 예약, 취소, 환불 관련 이슈를 운영자가 빠르게 처리할 수 있어야 한다.
- 고객 문의와 운영 이슈를 추적하고 처리 결과를 남길 수 있어야 한다.
- 내부 운영 기록과 권한 통제를 통해 실수와 오남용을 줄여야 한다.

## 2. 주요 사용자

### 2.1 운영자

- 판매자 승인, 예약 이슈 대응, 문의 답변을 수행한다.
- 일반 운영자 권한으로 일상 업무를 처리한다.

### 2.2 관리자

- 운영 정책 변경, 계정 권한 관리, 민감 기능 승인까지 수행한다.
- 환불 승인, 판매 중지, 제재 같은 고위험 액션을 담당한다.

## 3. 핵심 메뉴 구조

### 3.1 계정/상품 관리

- 판매자 계정 정보를 제공한다.
- 판매자별 숙소/객실 등록 현황을 조회하고, 상태를 관리할 수 있다.
- 외부 공급사 연동 상태를 조회한다.

### 3.2 예약 관리

- 예약 목록, 상세를 조회할 수 있고, 예약 상태 관리를 할 수 있다.

### 3.4 문의 관리

- 고객 문의와 판매자 문의를 관리한다.

### 3.5 감사 로그

- 어드민 내 액션에 대해 누가 언제 무엇을 변경했는지 기록한다.
- 운영 이슈 및 오류를 기록 및 조회한다.
